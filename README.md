# 🎮 CodeAlpha Hangman Game

⭐ **Python Programming Internship | CodeAlpha** ⭐

## 🌟 Project Overview

This project is a simple **text-based Hangman Game** developed using **Python** as part of my **Python Programming Internship at CodeAlpha**.

The game randomly selects a word from a predefined list, and the player guesses the word **one letter at a time**. The player is allowed a maximum of **6 incorrect guesses**.

## ✨ Features

⭐ 5 predefined words  
⭐ Random word selection  
⭐ One-letter-at-a-time guessing  
⭐ Displays correctly guessed letters  
⭐ Hides unguessed letters using `_`  
⭐ Maximum 6 incorrect guesses  
⭐ Detects repeated guesses  
⭐ Validates user input  
⭐ Displays winning and game-over messages  

---

## 🎮 How the Game Works

1. ⭐ The program stores 5 predefined words in a list.
2. 🎲 The `random` module selects one word randomly.
3. 🔤 The selected word is displayed using underscores.
4. ⌨️ The player enters one letter at a time.
5. ✅ Correct letters are revealed.
6. ❌ Incorrect guesses increase the incorrect-guess count.
7. 🏆 The player wins by guessing all letters correctly.
8. 🔚 The game ends after 6 incorrect guesses.
